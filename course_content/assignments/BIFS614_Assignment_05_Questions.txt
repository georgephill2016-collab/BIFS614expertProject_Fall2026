To explain what each command does in the previous block, I will break them down below:

    - fviz_pca_ind : this is used to visualize the individuals in a PCA plot

    - geom.ind = “point” : geom.ind stands for geometry of individuals, and = “point” refers to the command to instruct the plotting function to display individuals as individual points on the graph, without any text labels displayed.

    - pointshape= 21 : this dictates the shape of the data points representing the individuals (data points) on the PCA plot. The number 21 in ggplot2 refers to a circle with a border that is filled in by color.

    - pointsize = 2 : refers to setting the size of the points on the plot

    - fill.ind = wbcd$diagnosis : In this case, fill.ind controls the fill color of the points representing our indivduals, and wbcd$diagnosis refers to our column named “diagnosis” containing our categorical variables of malignant or benign, within our data frame “wbcd”.

    - col.ind = “black” : then refers to specify the color of the individuals on our graph as black

    - palette = “jco” : refers to applying the “JCO” color palette to our PCA plot, which is a color palette based on the style in the Journal of Clinical Oncology. In using this command, we can ensure that our PCA plot is easier to distinguish between different groups/categories.

    - addEllipses = TRUE : this instructs the plotting function to draw ellipses around the groups of data points in our PCA scatter plot to aid in being able to visualize and separate our different groups in our PCA.

    - label = “var” : is used to specify how the variables are identified on the plot

    - color.var = “black” : this specifies that the variable vectors should be colored black

    - repel = TRUE : this is used to prevent overlap of the data points or variables

    - legend.title = “Diagnosis” : this is used to set the title of the legend on the PCA plot to “diagnosis”

    - ggtitle(“2D PCA-plot from 30 feature dataset”) : this sets the title of the PCA plot to 2D PCA-plot from 30 feature dataset

    - theme(plot.title = element_text(hjust = 0.5)) : this is used to customize the appearance and the position of the main title of the PCA plot
